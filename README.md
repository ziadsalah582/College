# 🎓 College Desktop Application

A Java desktop application for managing a college system, including:

- Students
- Instructors
- Courses
- Departments
- Enrollments

This project includes a graphical user interface (GUI) built using AWT (Abstract Window Toolkit) in NetBeans, and it connects to a **SQL Server** database.

---

## 💡 Features

- Full **CRUD operations** (Create, Read, Update, Delete) for all entities.
- GUI built with manual layout using `setLayout(null)` and `setBounds()`.
- Separate forms for each entity (Student, Course, Department, Instructor, Enrollment).
- All GUIs are combined into one unified interface.
- Java + SQL Server integration using JDBC.

---

## 🛠️ Technologies Used

- Java (JDK 17)
- AWT (Abstract Window Toolkit)
- SQL Server
- NetBeans IDE
- JDBC
